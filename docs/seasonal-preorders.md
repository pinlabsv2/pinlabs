# Seasonal themes, preorders and research access

- **Admin → Brand Name:** select Original, Summer, Winter, Fall, Spring, Halloween, Black Friday, Christmas, New Year, Valentine’s Day or Easter. Custom colors override the seasonal action colors. Ambient decorations respect reduced motion and never intercept clicks. Original removes seasonal effects.
- **Minimum visitor age:** select 18 or 21 in Brand Name. This is a store eligibility policy, not a statement about a universal legal age. Visitors must also meet higher local requirements. The first-visit gate remembers acceptance on that browser; increasing the age requires a new acceptance. Policies, support and unsubscribe remain accessible. This is self-declaration, not verified ID.
- **Admin → Products:** enable preorder for the entire product (inherited by every variant), or independently on selected variants. Set a future expected dispatch time and finite stock. While preorder is enabled, stock means available preorder slots, not physical inventory. Full payment is collected. Slot reservations use the existing atomic stock flow; unpaid expiry/cancellation restores them exactly once. Paid cancellations require the existing admin/refund process.
- On arrival, reconcile physical stock and disable preorder. An elapsed dispatch date stops new preorder purchases until the admin updates the date or disables preorder. Previously purchased dates remain immutable on order details and invoices. This feature does not introduce automated partial shipment tracking or actual refund transfers.
- Checkout requires research/age confirmation and explicit acceptance of preorder dates. If a date changes, the server rejects a stale checkout so the buyer can refresh and accept the new date.
- **Admin → Policies → Load recommended drafts:** replaces editor contents only. Complete every `[COMPLETE: …]` marker, check actual provider/retention/delivery practices, and save to publish. Existing policies are never overwritten by a migration. Markdown source drafts are in `docs/policies/`. These are templates, not a guarantee of enforceability; obtain local legal review before publication. Research-only wording does not remove statutory consumer rights.
- Test with `node tests/seasonal-preorder.mjs`. The test uses an isolated, in-memory PGlite database and fake providers. It does not send emails or transfer funds.

Policy reference material: [EU withdrawal rules](https://europa.eu/youreurope/citizens/consumers/shopping/returns/index_en.htm), [EU delivery rights](https://europa.eu/youreurope/citizens/consumers/shopping/shipping-delivery/index_en.htm), [European Commission data protection information](https://commission.europa.eu/law/law-topic/data-protection/information-individuals_en).
